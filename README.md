# Mi portafolio de desarrollo web

Desarrollo tiendas online y aplicaciones web con PHP, JavaScript, CSS y MySQL. En mi portafolio reúno tres proyectos publicados, con distintos desafíos de catálogo, experiencia de compra y creación de currículums.

**[Ver mi portafolio](https://therealsogood-png.github.io/portafolio/)**

## Proyectos

### Ofertas Techorin
Tienda online de productos para bebé, hogar y cuidado personal. Incluye búsqueda con tolerancia a errores de escritura, promociones por cantidad, carrito y opciones de retiro y despacho en Colina.

[Visitar Ofertas Techorin](https://ofertastechorin.com/)

### Civora Vitae
Aplicación para crear currículums con plantillas ATS, edición con vista previa, evaluación del contenido y exportación a PDF.

[Visitar Civora Vitae](https://civoravitae.com/)

### Kathia Studio Beauty
Tienda de cuidado capilar con catálogo, favoritos, bolsa de compra, promociones y una presentación de los servicios del salón.

[Visitar Kathia Studio Beauty](https://kathiastudiobeuty.cl/)

## Tecnologías

- Desarrollo web: PHP, JavaScript, CSS y MySQL.
- Portafolio: HTML, CSS, JavaScript y WebGL.
- Publicación: GitHub Pages.

El portafolio incluye una letra K tridimensional interactiva, una mascota que sigue el cursor, vistas animadas de los proyectos y un diseño adaptable. Las animaciones respetan la preferencia de movimiento reducido y pueden pausarse.
